# ==========================================================================
#  R2 DOME - demo cycle
#  Runs every dome sequence back-to-back, forever.
#
#  This top block IS the main program. It must sit ABOVE the sub
#  definitions and it must never fall through, otherwise execution runs
#  into the first sub body and hits a "return" with an empty call stack
#  -> error 0x0080 (Script Call Stack Error).
#  begin/repeat never exits, so the subs below are only ever reached by
#  a real call. Tick "Run script on startup" to have it self-start.
# ==========================================================================

begin

  Dome_Pies_Open
  1500 delay

  Dome_Pies_Close
  1500 delay

  Dome_Panels_Open
  1500 delay

  Dome_Panels_Close
  1500 delay

  Dome_Pie_Wave
  1500 delay

  Whole_Dome_Open
  1500 delay

  Whole_Dome_Close
  1500 delay

  Dome_Flutter
  3000 delay

repeat
