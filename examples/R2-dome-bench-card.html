Loading it

  1. File ▸ Open settings file → R2-dome-padawan.mstr
  2. Apply Settings
  3. Do not press "Copy all Sequences to Script" — the script is already generated, and that would rebuild it from all twelve sequences and renumber your slots
  4. Tap LT + ◀ to home the dome, then work up
Slots are pinned. The eight are first in <Sequences>; your four originals sit after them, so even an accidental Copy-all keeps 0–7 correct.
The old script could never have worked. It was a begin/repeat loop with no sequence subroutines, so restartScript(0) landed on frame_0..17 and underflowed the stack.
homemode is Off everywhere. Servos are limp at power-up. Every sequence writes all 17 channels in its first frame, so any script leaves the dome in a known pose.
